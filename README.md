# 工蜂 Worker Bee · AI 技能包（Skills）

给 Claude Code / Codex / Workbuddy 等 AI 助手用的**进阶编排技能**。装上之后，
你可以直接用大白话指挥 AI 操作「工蜂 Worker Bee」——核弹级小红书 API 应用。

**先说清楚：日常基础采集不需要装任何技能。** 建任务、取结果这些，把工蜂
设置 → 接口开放 里「给 AI 的说明」整段粘给你的 AI 就够了——接口自带说明书
（`GET /api/docs`），AI 读完就会用。技能包沉淀的是**多步组合打法**：
那些靠一次次实战踩坑换来的判断标准和字段契约，AI 现场自己发明容易走弯路。

新安卓手机第一次接入是例外：不同品牌的 USB 安装限制和安全开关不一样。
`workerbee-phone-onboarding` 已带好经过校验的 ADB Keyboard 和 `u2.jar`：它会先帮你定位卡点，
引导你在手机上打开必要权限，再在你同意后单独补齐缺失组件。不用自己找安装包，也不用改源码。

## 五个技能

| 技能 | 什么时候自动触发 | 门槛 |
|---|---|---|
| `workerbee-phone-onboarding` | 新安卓手机首次连接、小米/Redmi 禁止安装，或缺 ADB Keyboard / `u2.jar` | 工蜂桌面软件 + USB 数据线；某些安全开关需用户在手机上确认 |
| `workerbee-content-mining` | 研究博主笔记打法、找带货账号、找未变现机会 | — |
| `workerbee-viral-notes` | 按**阅读数**找行业爆款笔记 | ⚠️ 需**小红书蓝V**资质 |
| `workerbee-feishu-delivery` | 导出结果到飞书多维表格 | 需配飞书应用凭证 |
| `workerbee-cargo-notes` | 盘某博主的带货/挂车笔记：按赞、时间、挂载商品筛选，无水印图+视频交付飞书表 | ⚠️ 需 **root 安卓手机** + 工蜂项目源码（进阶） |

技能之间会互相调用，你不用记它们的名字——正常提需求就行，AI 会自己判断该读哪个。

**关于蓝V那个**：小红书不公开笔记阅读数，只有蒲公英后台（需企业认证蓝V）看得到。
没有蓝V也能做爆款研究——AI 会自动改用「赞+藏+评」的互动热度来排序，效果对多数选题够用。
技能会在开工前先问你有没有资质，不会让你白跑一趟。

## 怎么安装

### Claude Code

把本仓库里 workerbee- 开头的五个文件夹复制到 `~/.claude/skills/`（Windows 是
`C:\Users\<你的用户名>\.claude\skills\`），重开一个会话即可。

### Codex

复制到 `~/.codex/skills/`（Windows：`C:\Users\<你的用户名>\.codex\skills\`）。

### Workbuddy

复制到 `~/.workbuddy/skills/`，或在 Skills Hub 里搜索并添加。

### 让 AI 自己装

把这段话发给你的 AI 助手：

> 请从 https://github.com/chenchen1010/workerbee-skills 下载 workerbee- 开头的全部技能文件夹，
> 复制到我的 AI 技能目录（Claude Code 是 ~/.claude/skills/，Codex 是 ~/.codex/skills/，WorkBuddy 是 ~/.workbuddy/skills/）。
> 工蜂的接口地址和钥匙我等下粘给你（在工蜂 设置 → 接口开放 点「复制这段给 AI」）。

## 装好之后怎么用

先确保工蜂桌面软件在运行，并且**设置 → 接口开放 → 本机接口**是打开的。

然后直接跟 AI 说人话就行：

- 「看看这个品类的博主都是怎么发笔记的」
- 「工蜂里点补装还是连不上这台小米，帮我完成首次连接」
- 「找找有哪些笔记评论区很火但还没做成商品的」
- 「找这个行业阅读数最高的爆款笔记」（会先问你有没有蓝V）
- 「把结果导出到飞书表格」

想要什么新玩法，也是一句话的事——比如「每次采完自动去重再按互动排序」，
直接跟你的 AI 说，它会基于接口说明书自己组合出来。**没有会不会写代码这回事。**

## 安全说明

- 技能只会调用工蜂在你本机开的接口，**数据不出你的电脑**（除非你让它导出到飞书）。
- 采集会真的占用你连接的安卓手机去操作小红书，AI 会在动手前先跟你确认。
- 你的接口钥匙等同密码，别发给第三方。
